# ブラウザの AI にマップを作らせて取り込む

ChatGPT・Gemini・Claude などの **ブラウザ版 AI** に「取り込める形」でファイルを
作ってもらい、このアプリの **読み込み** から入れる手順です。

## 手順

1. 下の「頼み方」をそのまま AI に貼り、`〈  〉` の中身だけ書き換える
2. 返ってきた JSON を `.json` ファイルとして保存する
   (ChatGPT ならコードブロック右上のコピー → メモ帳に貼って `map.json` で保存)
3. アプリの **メニュー → 読み込み** でそのファイルを選ぶ

`.json` のほか、`<script id="mindmap-data" type="application/json">…</script>` に
JSON を埋め込んだ `.html` も読み込めます。

---

## 頼み方 (これをコピーして貼る)

```
次の仕様どおりの JSON だけを、コードブロックで出力してください。
説明文は要りません。

【題材】〈ここに作りたい内容。例: 「Flutter の状態管理」を 3 階層でまとめて〉

【形式】
{
  "type": "mindmap_page",
  "version": 1,
  "page": {
    "id": "p1",
    "name": "〈ページ名〉",
    "pageType": "normal",
    "nodes": [ ... ],
    "connections": [ ... ]
  }
}

【nodes の各要素】※ id / title / x / y / color は必須
{
  "id": "n1",
  "title": "見出し",
  "x": 10000, "y": 10000,
  "color": 4285098345,
  "contentType": 1,          // 省略可。1 = メモ付き
  "memoText": "説明の文",     // contentType が 1 の時
  "width": 160, "height": 40  // 省略可
}

【connections の各要素】※ 全て必須
{ "fromId": "n1", "toId": "n2", "fromAnchor": 2, "toAnchor": 3 }
  fromAnchor / toAnchor は 0=上 1=下 2=右 3=左
  親から子へ引く時は fromAnchor:2, toAnchor:3

【配置のきまり】
・自動整列はされないので、座標は自分で決めること
・中心 (根) を x:10000, y:10000 に置く
・子は親から右へ +260、上下は +90 ずつずらして重ならないようにする
・孫はさらに右へ +260
・色は階層ごとに変える (ARGB の 10 進数。例 4285098345 / 4294940672 /
  4283215696 / 4294198070)

【注意】
・nodes は「配列」。オブジェクトの辞書にしないこと
・id は重複させない。connections の fromId / toId は必ず nodes の id と一致
・JSON 以外は出力しない (前置き・後書き・``` の外の文も不要)
```

## ギャラリーページを作らせたい時

`"pageType": "normal"` を `"pageType": "bookshelf"` に変えるだけです。
ギャラリーは並べ方をアプリが決めるので、座標は適当で構いません
(取り込んだ後に **AI アシスタントへ「整列して」** と頼めば詰め直せます)。

## 複数ページをまとめて作らせたい時

```
{
  "type": "mindmap_folder",
  "folder": { "name": "〈フォルダー名〉" },
  "pages": [ 〈page オブジェクトを並べる〉 ]
}
```

読み込むとフォルダーが 1 つ作られ、その中に全ページが入ります。

## うまくいかない時

| 症状 | 理由と直し方 |
|---|---|
| 「JSON が不正です」 | 説明文が混ざっている。コードブロックの中だけを保存する |
| 何も出ない / 一部だけ | `color` や `x` `y` が抜けている。必須項目を入れ直させる |
| 線が引かれない | `fromId` / `toId` が nodes の id と食い違っている |
| 全部重なっている | 座標が同じ。上の「配置のきまり」を守らせる |

> アプリの中の AI アシスタントに頼む場合は、この形式は要りません。
> 「〜のマップを作って」と普通に頼めば、そのまま作ってくれます。
